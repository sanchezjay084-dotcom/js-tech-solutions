JS TECH SOLUTIONS - FRONTEND REACT + VITE

REQUISITOS
- Node.js 18 o superior

INSTALACIÓN
1. Descomprime este proyecto.
2. Abre la carpeta en VS Code.
3. Abre una terminal en la carpeta.
4. Ejecuta:
   npm install
5. Después:
   npm run dev
6. Abre la dirección que te muestre Vite, normalmente:
   http://localhost:5173
